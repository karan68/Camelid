# Responsive LAN Chat evidence

Generated by `npm run smoke:lan-auth` from the authenticated LAN Chat flow on 2026-08-20. The smoke uses a scripted local backend, switches models, completes a streamed reply, and then captures the same rendered state at two constrained browser viewports.

- `01-mobile-portrait.png`: 360 x 800 compact portrait.
- `02-mobile-landscape-short.png`: 740 x 320 short landscape, representing reduced usable height after mobile browser chrome.

The executable smoke also checks 390 x 844 phone portrait, 844 x 390 phone landscape, 768 x 1024 tablet portrait, and 1440 x 900 desktop. For compact cells it asserts no document overflow, a single 40px composer toolbar row, visible model/send controls, at least 120px of message space, bounded notices, a settled navigation drawer, and reachability of the final composer tool.

Physical Android authentication, model switching, and streamed inference evidence remain in the parent PR's `frontend/design-evidence/lan-chat-e2e` directory. These images document only the responsive presentation change.
