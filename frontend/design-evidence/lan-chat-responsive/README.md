- `02-mobile-landscape-short.png`: 740 x 320 short landscape, representing reduced usable height after mobile browser chrome.

The executable smoke also checks 390 x 844 phone portrait, 480 x 320 narrow phone landscape, 844 x 390 phone landscape, 768 x 1024 tablet portrait, and 1440 x 900 desktop. The compact treatment is global at 860px and below, including tablets and narrow desktop windows; it is not limited to LAN mode. For compact cells the CI smoke asserts no document overflow, a single 40px composer toolbar row, visible model/send controls, at least 120px of message space, bounded notices, a settled navigation drawer, and simultaneous reachability of the sticky model picker and final composer tool at maximum horizontal scroll.

The PNGs are dated review evidence, not cross-platform pixel-golden tests. CI exercises the built CSS through the geometry and interaction assertions above; the checksum manifest protects the committed evidence bytes.

Physical Android authentication, model switching, and streamed inference evidence remain in the parent PR's `frontend/design-evidence/lan-chat-e2e` directory. These images document only the responsive presentation change.
