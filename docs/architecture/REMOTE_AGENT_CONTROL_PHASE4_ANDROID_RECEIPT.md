## Native Boundary

The local Expo module links the generated Kotlin UniFFI binding and target-native Rust library. JavaScript receives only:

- an opaque KeyStore reference;
- the static public key;
- opaque handshake and transport handles;
- base64url ciphertext, plaintext protocol JSON, and handshake hash.

The private static key is generated by Rust, consumed once inside Kotlin, wrapped with a per-device AES-256-GCM key in Android Keystore, and stored under `noBackupFilesDir`. The transient JVM private-key buffer is zeroed. Removing a device identity deletes both encrypted bytes and the Keystore key.
